  Note this capture caught it CLAMPED: equal bounds is VRR_STATE_ACTIVE_FIXED,

  [0]:  2242  82  0  10  0  6749  2249  1  1  4224  384  0  88  0  4399  2249  0  0

    1188000000 / (4400 * 6750) =  40.00 Hz
    1188000000 / (4400 * 2250) = 120.00 Hz
  i.e. armed across exactly the 40-120 Hz window the C9 advertises in its
  HF-VSDB. The 4500/4500 row above is the same state pinned to 60.00 Hz.

  NOT established, either way: whether the sink tracks the varying rate. Every
  reading here is source-side. Same for ALLM -- content type 4 is a property the
  driver sets, not proof the TV entered game mode. The TV's own "Instant Game
  Response" indicator is the check that would settle both; it has not been run.
